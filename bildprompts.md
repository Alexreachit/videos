# Bildprompts zum Skript

Diese Vorlage sorgt dafür, dass die Figuren in allen Bildern gleich aussehen.
Kopiere pro Szene den **Stil-Block** und füge die **Szenenbeschreibung** an.
Benutze für alle Bilder denselben Bilddienst und dasselbe Gespräch.

## Stil-Block (immer vorne anhängen)

```
Flat cartoon illustration, thick black outlines, simple shapes, muted warm colors,
16:9 landscape. Main character: round cream-colored head, dot eyes, small smile,
dark gray baseball cap, dark navy jacket over light blue shirt. Colleague: round
beige head, dark green baseball cap, khaki work shirt with ID badge.
Office break room setting. No text, no letters, no logos.
```

## Szenen (Beispiel zu script.txt)

| Nr. | Szenenbeschreibung |
|-----|--------------------|
| 01 | Main character puts a lunch box on the counter of an office kitchen, Monday morning light |
| 02 | Close-up of the main character looking relaxed, not noticing anything |
| 03 | Colleague enters the kitchen and smiles at the lunch box |
| 04 | Colleague with a sly smile, thought bubble with a small calendar |
| 05 | Colleague asks the main character something, hand gesture open |
| 06 | Main character nods hesitantly, sweat drop on the forehead |
| 07 | Wall clock showing two hours later, main character at a desk with papers |
| 08 | Calendar on a wall with a recurring red-circled Friday slot |
| 09 | Small snowball rolling downhill getting bigger |
| 10 | Main character holding up a hand to draw a boundary line on the floor |
| 11 | Main character calmly speaking, speech bubble empty, relaxed pose |
| 12 | Main character with free time, drinking coffee, window light |

Tipp: Wenn der Dienst ein Bild mit Text oder Buchstaben erzeugt, schreibe
"no text" noch einmal an das Ende des Prompts und erzeuge es neu.

Speichere die Bilder als `01.png`, `02.png`, ... im Ordner `bilder/`.
(Auch `.jpg` und `.webp` gehen.)
